# Aplikasi Ucapan Ulang Tahun

Aplikasi web sederhana bertema ulang tahun dengan:

- Ucapan dinamis berganti otomatis
- Countdown ke tanggal ulang tahun
- Tombol kejutan dengan animasi confetti
- Musik latar sederhana dari Web Audio API
- Tampilan responsif untuk desktop dan mobile

## Cara Menjalankan

1. Buka file `index.html` langsung di browser.
2. Atau jalankan dengan live server agar proses development lebih nyaman.

## Ubah Tanggal Ulang Tahun

Edit bagian berikut pada `scripts/app.js`:

- `BIRTH_MONTH` untuk bulan
- `BIRTH_DAY` untuk tanggal

Contoh: 17 Agustus berarti `BIRTH_MONTH = 8` dan `BIRTH_DAY = 17`.
